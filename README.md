# Charm the Commuter: Forecast a City That Isn't

One line of weather forecast (≤140 characters) for Morrowmere, a city that
does not exist.

> Morrowmere: sunny spells, 21°, buses running on time for once — the clouds apologised and brought cake.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
